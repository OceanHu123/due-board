How it works

  1. Sign in with a magic link (no password).
  2. Paste your own Canvas and Ed API tokens — stored encrypted on the server.
  3. Open the board anytime, or get email reminders at 08:00 / 18:00 (configurable).

Security

  • Tokens never ship to the browser after save; only ciphertext is stored.
  • Each account only sees its own dues.
  • Revoke tokens anytime in Canvas / Ed settings, and clear them here.

Demo uses fictional deadlines — no real LMS credentials.
